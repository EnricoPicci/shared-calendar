Plan the implementation of a new feature that allows to define a number of concurrent users per type.

This means that a type can have a number of users that can book the same slot.

For instance, the type Piscina, can accommodate up to 3 users in the same slot, while the type Studio just 1.

The admin can force and add more users than the limit in a certain slot.

The default number of concurrent users is 1.
